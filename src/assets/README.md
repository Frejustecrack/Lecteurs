# Visuels de l'application

## Fond d'écran de la page de connexion

Déposez ici le visuel sous le nom **`fond-connexion`** avec l'une de ces extensions :
`fond-connexion.jpg`, `fond-connexion.jpeg`, `fond-connexion.png` ou `fond-connexion.webp`.

Il est détecté automatiquement au build (`import.meta.glob` dans `src/pages/Login.tsx`) :
aucune modification de code n'est nécessaire. Un seul fichier doit porter ce nom.

Tant qu'aucun fichier n'est présent, la page de connexion affiche le dégradé bleu CDLJ.

Conseils : format paysage, au moins 1600 px de large, sujet centré (un voile sombre
est appliqué par-dessus pour garantir la lisibilité du formulaire).
